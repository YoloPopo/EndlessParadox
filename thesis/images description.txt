**11. control loop flowchart.png**
A flowchart titled "Closed-Loop Control Flow". It begins with an initialization block containing $t=0$ and initial joint state $\theta_0$. This enters a main loop starting at "Current joints $\theta_t$". The flow proceeds linearly through "Physical / Simulated Robot", "Dual Cameras", and "Self-Model (CNN)" to generate "Predicted Position $P_t$". An external input labeled "Target $P_{target}$" joins the flow at a block labeled "Calculate Error: $e_t = P_{target} - P_t$". The next step is "Calculate Update: $\Delta \theta_t = J^+ e_t$", followed by "Apply Joint Limits & Execute: $\theta_{t+1} = \theta_t + \alpha \Delta \theta_t$". A decision diamond then asks "Error < Threshold or $t > t_{max}$?". If "Yes", the process points to "Stop". If "No", an arrow loops back to "Current joints $\theta_t$" for the next iteration.
